# Infinite Family Tree

Private family tree site at https://family.infinitefate.com. Relatives sign up, an admin approves them,
and approved members can view, edit and add people, photos and documents.

This repository holds only the site's code. Family data lives in Supabase behind sign-in and row-level
security; nothing about the family is stored here.

- `index.html` — the site (built from the research project's `viewer/template.html` and `site/shell.html`)
- `config.js` — Supabase project URL and publishable key
- `CNAME` — custom domain for GitHub Pages
